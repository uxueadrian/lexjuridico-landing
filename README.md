# Lexjuridico Pineda & Asociados — Landing

Landing page de **Lexjuridico Pineda & Asociados**, despacho jurídico. Sitio estático en español construido con **Astro** y **Tailwind CSS**.

## Stack

- **Astro** (sitio estático)
- **Tailwind CSS**
- **@lucide/astro** (iconografía)
- **EmailJS** (formulario de contacto)

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Build de producción

```bash
pnpm build      # genera dist/
pnpm preview    # sirve el build
```

## Notas

- Los datos aún no confirmados por el cliente se marcan con `DATA_PENDING` y son intercambiables sin tocar la estructura.
